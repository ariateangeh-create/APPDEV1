# Assignment 5 — ReactJS Styling

A responsive login-page recreation starter built with React and Vite.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite (usually `http://localhost:5173`).

## Styling concepts used

- **Global CSS** (`src/styles/global.css`): reset, base typography, focus states, and design tokens.
- **CSS Modules** (`src/App.module.css`): component-scoped layout and visual styling.
- **Design tokens**: CSS custom properties for colors, typography, radii, and shared values.
- **React components**: `Brand`, `LoginForm`, and `App`.
- **Responsive layout**: desktop split-screen layout switches to a single-column login view on small screens.
